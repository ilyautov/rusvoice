# Как помочь

Спасибо. Самый полезный вклад здесь — не код, а **слово, которое читается неверно**:
словарь произношения растёт только от живых ошибок, придумать их за столом нельзя.

## Слово читается не так

Заведите [issue «слово читается неверно»](https://github.com/ilyautov/rusvoice/issues/new?template=new-word.md)
или сразу PR:

```bash
python3 -m rusvoice dict add brands Netlify Нетлифай
python3 -m rusvoice dict hear brands Netlify      # услышать, а не прочитать
python3 -m rusvoice dict bump                     # поднять версию правил
```

Три вещи, о которых стоит знать заранее:

1. **`add` проверяет строку, а не звук.** Он убеждается, что слой выдаёт «Нетлифай», и
   на этом всё. Как это прочтёт модель — знает только `hear`: на одиночном слове синтез
   ведёт себя иначе, чем в потоке речи.
2. **Твёрдая «э» — словарь, а не правило.** Сплошного «е→э» не существует: «лес», «дело»,
   «текст» читаются мягко. Основа, задевающая мягкие слова, отклоняется намеренно.
3. **Правка словаря не инвалидирует аудио-кэш сама.** Отсюда `dict bump`. Без него правка
   «не сработает», и выглядеть это будет как дефект модели.

Метка ударения `+` ставится на многосложных. На односложном слове F5 отыгрывает её как
нажим — получается «нейрослоп», и причину потом не найти.

## Код

```bash
pip install -e ".[accent,numbers,ui,ref,dev]"
python -m pytest tests/ -q          # 145 тестов, ~40 секунд
python scripts/prepublish_check.py  # личного и служебного в репозитории нет
ruff check rusvoice tests
```

Тесты гоняются и **без единой опциональной зависимости** — так живёт ядро у большинства
пользователей. Тест, которому нужна экстра, обязан скипаться с внятной причиной
(`@needs_numpy`), а не падать: сырое `ModuleNotFoundError` читается как «репозиторий
сломан», хотя сломана только установка.

Ещё три вещи, которые ловились здесь болью:

- **Не заводите вторую копию значения.** Версия правил живёт ровно в одном месте рядом с
  самими правилами. Копия, которую надо помнить, однажды не поднимается.
- **Проверка обязана уметь падать.** Если добавили измеритель — сломайте предмет нарочно
  и убедитесь, что он это заметил. Зелёный измеритель, ничего не измеряющий, хуже
  отсутствующего.
- **Молчание — дефект.** Если пакет чего-то не может (нет RUAccent, нет ffmpeg, эталон
  не про то аудио), он обязан сказать это словами и ненулевым кодом возврата.

## Что сюда не поедет

Голоса, эталоны и любые персональные данные. Пакет не знает ничьего голоса — это его
свойство, а не гигиена: зашитый путь к эталону превращает «голос не выбран» в «эталона
нет», и человек не понимает, что делать.
